Calculator Web Application

Overview

This project is a basic Calculator Web Application developed using HTML, CSS, and JavaScript. It provides a simple and interactive interface for performing arithmetic calculations. The calculator is designed with a user-friendly layout and supports real-time calculation results.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear screen functionality
- Interactive button-based input
- Real-time result display
- Responsive and attractive user interface
- Keyboard support (Bonus Feature)

Technologies Used

- HTML
- CSS
- JavaScript

Project Structure

- "index.html" – Calculator layout and structure
- "style.css" – Styling and user interface design
- "script.js" – Calculator logic and functionality

How to Use

1. Open the calculator in a web browser.
2. Click the buttons or use your keyboard to enter numbers and operators.
3. Press "=" to view the result.
4. Use "C" or Clear button to reset the display.

Learning Outcomes

Through this project, I learned:

- DOM manipulation using JavaScript
- Event handling
- User input validation
- Creating responsive web interfaces
- Implementing arithmetic operations programmatically
